## 第I部　総論

### 1. 術後不整脈の全体像

心臓外科術後は、**炎症・カテコラミン・電解質変動・心房伸展・心膜液貯留・虚血再灌流**を背景に不整脈が高頻度に発生する。臨床的に重要なのは下記。

| 不整脈 | 術後の概略 |
|---|---|
| **心房細動（POAF）** | 最多。術後2–4日にピーク、術式により15–50%。後述（第II部1） |
| 心房粗動・心房頻拍 | POAFと連続的。切開瘢痕起源の心房内リエントリーを含む |
| 発作性上室頻拍（AVNRT/AVRT） | 比較的低頻度。アデノシン/ATP・Ca拮抗薬が中心 |
| 心室期外収縮・非持続性VT | 高頻度だが多くは良性。電解質・虚血の評価が要 |
| 持続性VT・VF・electrical storm | 低頻度だが致死的。虚血・グラフト不全・電解質を除外 |
| Torsades de Pointes（TdP） | QT延長薬・低K/低Mgが誘因。Mg・心拍数上げが要 |
| 徐脈（洞機能不全・房室ブロック） | 弁手術（特に大動脈弁・三尖弁）後に多い。一時心外膜ペーシングで対応、遷延例は恒久ペースメーカ |
| 術後心停止 | 専用蘇生プロトコル（CALS/CSU-ALS）が一般ACLSと異なる（第II部8） |

### 2. モニタリングと一時心外膜ペーシングワイヤー

- 術直後は**持続心電図モニタリング**が標準。POAFは70%が術後4日以内・90%が7日以内に発生するため、この期間の監視が重要。
- **一時心外膜ペーシングワイヤー**（心房・心室）はCABG/弁手術で広く留置される。徐脈・房室ブロック時の即時ペーシングに加え、心房ワイヤーは**心房電位の記録（P波同定による上室性 vs 心室性の鑑別）**や**overdrive pacing**にも有用。
- 術後心停止時には心外膜ワイヤーを**DDD 80–100 bpm・最大出力**で接続する（STS 2017：Class I, Level C）。

### 3. 抗凝固・出血のバランス（術後特有の制約）

術後早期は**外科的出血リスク**があるため、抗凝固開始は「出血リスクが落ち着いてから」が原則。POAFの抗凝固は塞栓リスクと出血リスクを個別に天秤にかける（第II部1-6）。

## 第II部　不整脈別 各論

### 1. 術後心房細動（POAF）★最重点

#### 1-1. 発生率・発症タイミング

| 指標 | 値（出典） |
|---|---|
| 全体発生率 | **20–50%**（STS 2026）。**30–50%**（ESC 2024）。**15–50%**（EACTS 2024） |
| 術式別 | 単独CABG **20–30%** / 単独弁手術 **30–40%** / 複合手術 **40–50%**（STS 2026） |
| 発症タイミング | 術後 **2–4日**にピーク。**70%が4日以内、90%が7日以内**（STS 2026）。EACTS：**約90%が術後6日以内** |
| 性状 | 多くは発作性・速い心室応答。連続モニタ研究では多くが短時間（中央値4分、累積中央値50分） |
| 退院後 | 20–30%が退院後も持続・再発 |

#### 1-2. リスク因子（STS 2026）

- **術前：** 高齢、左房拡大、肥満、睡眠時無呼吸、左室収縮/拡張障害、既存の無症候性上室性不整脈、COPD、糖尿病、慢性腎臓病、β遮断薬の中断。
- **術中：** 人工心肺、大動脈遮断時間延長、術式の複雑さ。
- **術後：** 静注カテコラミンの使用、心膜液/血液の貯留。

#### 1-3. 予後への影響

| アウトカム | 関連（出典） |
|---|---|
| 周術期死亡 | OR 1.92（STS 2026） |
| 脳卒中 | OR 2.17（STS 2026）／OR 4.09・4倍（EACTS 2024） |
| 心筋梗塞 | OR 1.28 |
| 急性腎障害 | OR 2.74 |
| 長期 | 再発AFが **4–5倍/5年（ESC 2024）〜8倍/6年（EACTS 2024）**／10年死亡 **29% vs 23%（OR 1.51）**（EACTS 2024） |
| 医療費 | 米国で年間20億ドル超 |

#### 1-5. 急性期マネジメント

```
POAF 発症
  │
  ├─ 血行動態 不安定（低血圧・心不全・虚血）
  │     └─ 同期電気的除細動（100–200 J 二相性）★STS2026: COR I, LOE C-EO
  │         （+ 抗不整脈薬併用：ACC/AHA 2023 COR 1, B-R）
  │
  └─ 血行動態 安定
        ├─ レートコントロール（目標 HR<100 bpm）… 第III部の β/Ca/ジギタリス
        │     ACC/AHA: β遮断 COR 1(A)、非DHP CCB COR 1(B-R)
        │     EACTS: 安定・無症候はレートコントロール Class IIa, B
        └─ リズムコントロール（薬理学的/電気的除細動）
              EACTS: 安定POAFはリズムコントロール Class I, B
              STS2026: レート vs リズムは どちらも妥当 COR IIb, LOE B-R

```

- **DC除細動前**：AF>48時間かつ抗凝固未施行例では、左心耳血栓を画像で除外（ACC/AHA 2023, COR 1, B-R）。
- **30–60日フォロー**：レートコントロール例で洞調律に戻らなければ、十分な抗凝固後に除細動を検討（ACC/AHA, COR 2a, C-LD）。

#### 1-6. 抗凝固療法

| 推奨 | 出典・格付け |
|---|---|
| POAFへのルーチン経口抗凝固（塞栓リスクと出血を勘案） | STS 2026：**COR IIb, LOE B-NR** |
| DOAC > VKA（出血リスク低減） | STS 2026：**COR IIb, LOE B-NR**（メタ解析で出血RR 0.74） |
| 高リスク例で長期OAC | ESC 2024：**Class IIa, Level B** |
| 持続POAF退院時 → OAC ≥4週、その後再評価 | EACTS 2024：**Class I, Level B** |
| 洞調律退院時 → OAC ≥4週 考慮 | EACTS 2024：**Class IIb, Level B** |
| 術後60日間の抗凝固（出血が許容されれば）、その後再評価 | ACC/AHA 2023：**COR 2a, LOE B-NR** |
| POAF発症24時間以内の治療用量UFH/LMWH | EACTS 2024：**Class IIa, Level C** |

- **開始タイミング**：外科的出血が落ち着いてから。**機械弁置換後はワーファリン必須**。

### 2. 心房粗動・心房頻拍

- POAFと連続的に扱われることが多く、**レートコントロール・リズムコントロールの原則はPOAFに準じる**。
- JCS 2020（薬物治療）：
  - 血行動態**安定**の心房粗動 → IV/経口 **ジルチアゼムまたはベラパミルでレートコントロール：COR I, LOE A**。
  - 血行動態**不安定**の心房粗動 → IV **ランジオロール：COR IIa, LOE B**。
  - 症候性心房粗動の停止に IV **アミオダロンまたはニフェカラント：COR IIa, LOE C**（IVクラスIIIはNHI適応外の点に注意）。
  - 薬剤抵抗性/禁忌の術後遷延性粗動 → **DC除細動：COR IIa, LOE C**。
- 切開瘢痕起源の心房内リエントリー頻拍は薬剤抵抗性のことがあり、難治例はカテーテルアブレーションが選択肢。

### 3. 発作性上室頻拍（AVNRT / AVRT）

- 頻度は高くないが、規則的なnarrow QRS頻拍として術後にみられる。
- **第一選択：迷走神経刺激 → アデノシン三リン酸（ATP）急速静注**（第III部）。
  - 日本では海外のadenosineに代えて**ATP製剤（アデホス-Lコーワ注 等）**を急速ワンショット静注＋後押しフラッシュで使用。⚠️ **PSVTは添付文書上の適応外**。
- ATP無効/再発例：**ベラパミル（ワソラン静注）**（第III部）。
- WPW併存のAFには房室結節抑制薬（ジゴキシン・非DHP CCB・β遮断薬）を**避ける**（順行伝導促進の危険）。

---

### 4. 心室期外収縮・非持続性VT

- 術後早期は高頻度。多くは良性だが、**虚血（グラフト不全）・電解質異常（低K・低Mg）・カテコラミン過剰**を評価。
- まず**是正可能な誘因の補正**（K ≥4.0–4.5 mmol/L、Mg補正）。
- 症候性/頻発例で器質的心疾患がある場合は β遮断薬。基礎心機能低下例ではクラスIC薬を避ける（JCS 2020）。

---

### 5. 持続性VT・VF・electrical storm

#### 診断・初期対応
- 血行動態不安定なVT/VF → **即時電気的除細動**。術直後は第II部8（術後心停止プロトコル）に従う。
- 必ず**可逆的誘因**（虚血/グラフト不全、タンポナーデ、電解質、低酸素、QT延長薬）を検索。

#### Electrical storm（24時間以内に3回以上の持続性VA：ESC 2022）

| 介入 | ESC 2022 |
|---|---|
| 鎮静（軽度〜中等度） | **Class I, Level C** |
| **β遮断薬（非選択的が望ましい）＋IVアミオダロン** | **Class I, Level B** |
| 同期電気的除細動 | **Class I, Level B** |
| incessant VT/storm（SMVT, 薬剤抵抗性）へのカテーテルアブレーション | **Class I, Level B** |
| 難治例の機械的循環補助（MCS） | **Class IIb** |
| アミオダロン抵抗性stormに **ランジオロール** | 有効性の記載あり（narrative） |

#### VT/VFへの抗不整脈薬（JCS 2020）
- 電気的除細動後の持続性/反復性・血行動態不安定VT蘇生に **IVアミオダロンまたはニフェカラント：COR IIa, LOE A**。
- 血行動態**安定**のmonomorphic持続性VTに **IVプロカインアミド：COR IIa, LOE A**。

---

### 6. Torsades de Pointes（TdP）/ QT延長

- 誘因：QT延長薬（**ソタロール、ベプリジル、一部の抗菌薬・制吐薬**等）、低K・低Mg、徐脈。
- 対応（ESC 2022）：
  - **IVマグネシウム＋カリウム補充：Class I, Level C**。
  - **心拍数を上げる**（イソプロテレノール or overdrive 経静脈/心外膜ペーシング）：後天性LQTの反復TdPに **Class I, Level C**。
  - **アミオダロン・ソタロールは禁忌**（QTをさらに延長）。
- 原因薬の中止とQT監視。

### 7. 徐脈性不整脈（洞機能不全・房室ブロック）と一時/恒久ペーシング

> 一次資料：**ESC 2021ペーシングGL・JCS/JHRS 2019非薬物治療GL・HRS/APHRS/LAHRS 2023生理的ペーシングGL**（いずれも本リポジトリ収載）。

#### 発生・背景
- 房室ブロック（AVB）は **心臓手術後の約14%、再弁手術後の約8%** に生じる（ESC 2021）。洞機能不全（SND）は **右側房切開や経中隔上方アプローチ（僧帽弁手術）** の後にみられる。
- ペースメーカ植込みは **CABGより弁手術後に多い**（ESC 2021）。**大動脈弁置換（石灰化重度・再手術）・三尖弁手術**で頻度が高く、TAVI後の新規LBBB・高度AVブロックも臨床的に重要。

#### 急性期対応
- **一時心外膜ペーシング**で即時対応（DDDで房室同期を維持）。
- 薬物的ブリッジ：**アトロピン**（迷走神経性/症候性徐脈）、無効時 **イソプレナリン**（第III部）。JCS 2020：交感神経刺激薬またはアトロピンをペースメーカへのブリッジに **COR IIa, LOE C**。
- 薬剤抵抗性で血行動態を損なう徐脈性不整脈には **一時経静脈ペーシング**：ESC 2021 **Class I, Level C**。

#### 恒久ペースメーカ（PPM）の判断 — 観察期間が鍵

| 推奨 | 格付け |
|---|---|
| 術後の高度/完全AVB：**少なくとも5日間の臨床観察**を行い一過性か（回復するか）を評価。ただし補充調律が低/欠如で回復が見込めない完全AVBでは観察期間を短縮しうる | ESC 2021：**Class I, Level C** |
| **術後に回復が期待できない**高度/完全AVB → 恒久ペースメーカ | JCS 2019（表7）：**COR I, LOE C** |
| 機械弁三尖弁置換後にペーシングを要する場合、**経弁的RVリードは避ける** | ESC 2021：**Class III, Level C** |

- 補足（ESC 2021）：臨床的には通常 **3–7日の観察**。完全AVBが術後24時間以内に発生し48時間持続する場合は1–2週以内の回復が見込み薄く、早期植込みを考慮。一方で **SND植込み例の60–70%・AVB植込み例の最大25%はフォロー時にペースメーカ非依存**であり、過剰植込みに注意。

#### TAVI後の伝導障害（ESC 2021）

| 推奨 | 格付け |
|---|---|
| TAVI後 **24–48時間持続**する完全/高度AVB → 恒久ペーシング | **Class I, Level B** |
| TAVI後の **新規・交代性脚ブロック** → 恒久ペーシング | **Class I, Level C** |
| RBBBがありペーシング適応のない患者への **TAVI前の予防的PPMは不要** | **Class III, Level C** |

#### ペーシング様式
- 高頻度の心室ペーシングが見込まれる場合は、**ペーシング誘発心筋症の回避**の観点から His束/左脚領域ペーシング・CRTを考慮（HRS/APHRS/LAHRS 2023）。

### 8. 術後心停止（CALS / CSU-ALS プロトコル）

心臓外科術後の心停止は**一般ACLSと異なる専用プロトコル**で対応する（STS 2017 CSU-ALS／EACTS 2009 CALS）。AHA 2025もこれをPart10へ委譲。詳細な薬剤希釈は本リポジトリの `CVCU_Emergency_Response_Protocol.md` を参照。

| 項目 | 推奨（STS 2017） |
|---|---|
| **VF/無脈性VT** | **3連続ショックを心臓マッサージ介在なしで先行**：Class I, Level B（除細動のためECMを最大1分まで遅らせてよい：Class IIA, Level B） |
| 3回失敗後 | **緊急再開胸（5分以内）**：Class I（Level B／5分以内 Level C） |
| 動脈圧 < 60 mmHg | 速やかに再開胸を考慮 |
| **asystole/高度徐脈** | 心外膜ペーシングワイヤーを **DDD 80–100 bpm・最大出力**で接続：Class I, Level C |
| **エピネフリン/バソプレシン** | **ルーチン投与は推奨しない：Class III(Harm), Level C**（経験者の判断で少量 50–300 µg のみ） |
| アトロピン | ルーチン非推奨：Class III(No Benefit), Level C |
| 全持続注入薬 | 心停止時は**いったん停止**：Class IIA, Level C |
| IABP | 圧トリガーモードに：Class IIA, Level C |
| AED | 心臓外科患者には**使用しない**：Class III(Harm), Level C |
| 抗不整脈 | アミオダロン 300mg→（再発時）150mg→900mg/24h、リドカイン 1 mg/kg |

## 第III部　薬剤各論 — 日本採用薬（一般名・商品名・希釈方法・投与方法）

### A. レートコントロール薬

#### A-1. ランジオロール塩酸塩 ★日本の術後レートコントロール第一選択
- **商品名（製販元）：** オノアクト点滴静注用 50mg / 150mg（小野薬品工業）
- **特徴：** 超短時間作用型・高β1選択性（半減期約4分、エステラーゼ代謝）。**心機能低下例でも血圧低下が少ない**ため術後に好適。
- **適応：** 手術時／**手術後の循環動態監視下における頻脈性不整脈**、心機能低下例の頻脈性不整脈（AF/AFL/洞性頻脈）等。
- **希釈方法：** 50mg を生理食塩液等で溶解（添文記載の調製例：**50mgを5mLに溶解＝10mg/mL**、または20mL／心機能低下例は**50mgを50mLに溶解＝1mg/mL**）。
- **投与方法（用法・用量）：**

| 状況 | レジメン |
|---|---|
| **手術後の頻脈性不整脈（緊急処置）** | **0.06 mg/kg/min を1分間 → 0.02 mg/kg/min** で持続。5–10分で目標徐拍が得られなければ **0.125 mg/kg/min を1分間 → 0.04 mg/kg/min**。以後 0.01–0.04 mg/kg/min で調節 |
| 手術時の頻脈性不整脈 | 0.125 mg/kg/min を1分間 → 0.04 mg/kg/min、0.01–0.04で調節 |
| 心機能低下例の頻脈性不整脈 | **1 µg/kg/min** 開始 → 1–10 µg/kg/min で調節 |
| 生命に危険のある難治性不整脈 | 1 µg/kg/min 開始 → 1–10、VF/不安定VT再発時は**最大 40 µg/kg/min** |
| 敗血症に伴う頻脈性不整脈 | 1 µg/kg/min 開始 → **最大 20 µg/kg/min** |

- **注意：** 目標心拍数到達後は維持に必要な最低速度で。血圧低下に注意。

#### A-2. ビソプロロール／カルベジロール（経口β遮断薬）

- POAF予防・退院後レートコントロールの経口主力。

#### A-3. ジルチアゼム塩酸塩（非DHP Ca拮抗薬）
- **商品名（製販元）：** ヘルベッサー注射用 10 / 50（田辺ファーマ＝旧田辺三菱）
- **適応・位置づけ：** 上室性頻脈性不整脈のレートコントロール。**β遮断が禁忌/不十分（喘息等）な例の代替**。
- **希釈方法：** 10mg または 50mg を **5mL以上の生理食塩液またはブドウ糖注射液に用時溶解**。
- **投与方法：**
  - 〈頻脈性不整脈（上室性）〉 1回 **10mg を約3分間で緩徐静注**（年齢・症状で適宜増減）。
  - ⚠️ 持続静注 **5–15 µg/kg/分** は添付文書上は〈手術時の異常高血圧／高血圧性緊急症〉の用法（**不整脈レートコントロールには適応外**）。上室性頻脈の承認用法は上記10mgボーラスのみ（不安定狭心症は1–5 µg/kg/分）。

#### A-4. ベラパミル塩酸塩（非DHP Ca拮抗薬）

- **希釈・投与方法：** **5mg を生理食塩液またはブドウ糖で希釈し、5分以上かけて緩徐静注**（JCS 2020 表74）。

#### A-5. ジゴキシン（ジギタリス）
- **商品名（製販元）：** ジゴシン注 0.25mg（太陽ファルマ）／経口メチルジゴキシン＝ラニラピッド錠（中外製薬）
