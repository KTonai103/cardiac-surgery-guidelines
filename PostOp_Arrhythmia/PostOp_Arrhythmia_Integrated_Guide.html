成人心臓外科 術後不整脈 — 発生率・リスク・対応・薬剤 統合ガイド

成人心臓外科の術後不整脈について、各不整脈の発生率・リスク・診断・対応を主要ガイドライン横断でまとめ、日本で採用されている薬剤の一般名・商品名・製造販売元・希釈方法・投与方法・用量を一次資料（PMDA電子添文）まで遡って記載した統合リファレンス。

対象： 成人（後天性）心臓外科術後。小児／先天性心疾患術後のJET等は対象外。 最重点： 術後心房細動（POAF）。 作成： 2026-06-11 ／ ✅ Fact-check済 2026-06-11（COR/LOE・発生率・薬剤用量を収載PDF＋PMDA添付文書と照合。末尾callout参照）。薬剤用量・希釈は臨床使用前に必ず最新の添付文書で確認すること。

第I部　総論

1. 術後不整脈の全体像

心臓外科術後は、炎症・カテコラミン・電解質変動・心房伸展・心膜液貯留・虚血再灌流を背景に不整脈が高頻度に発生する。臨床的に重要なのは下記。

不整脈 術後の概略
心房細動（POAF） 最多。術後2–4日にピーク、術式により15–50%。後述（第II部1）
心房粗動・心房頻拍 POAFと連続的。切開瘢痕起源の心房内リエントリーを含む
発作性上室頻拍（AVNRT/AVRT） 比較的低頻度。アデノシン/ATP・Ca拮抗薬が中心
心室期外収縮・非持続性VT 高頻度だが多くは良性。電解質・虚血の評価が要
持続性VT・VF・electrical storm 低頻度だが致死的。虚血・グラフト不全・電解質を除外
Torsades de Pointes（TdP） QT延長薬・低K/低Mgが誘因。Mg・心拍数上げが要
徐脈（洞機能不全・房室ブロック） 弁手術（特に大動脈弁・三尖弁）後に多い。一時心外膜ペーシングで対応、遷延例は恒久ペースメーカ
術後心停止 専用蘇生プロトコル（CALS/CSU-ALS）が一般ACLSと異なる（第II部8）

2. モニタリングと一時心外膜ペーシングワイヤー

  • 術直後は持続心電図モニタリングが標準。POAFは70%が術後4日以内・90%が7日以内に発生するため、この期間の監視が重要。
  • 一時心外膜ペーシングワイヤー（心房・心室）はCABG/弁手術で広く留置される。徐脈・房室ブロック時の即時ペーシングに加え、心房ワイヤーは心房電位の記録（P波同定による上室性 vs 心室性の鑑別）やoverdrive pacingにも有用。
  • 術後心停止時には心外膜ワイヤーをDDD 80–100 bpm・最大出力で接続する（STS 2017：Class I, Level C）。

3. 抗凝固・出血のバランス（術後特有の制約）

術後早期は外科的出血リスクがあるため、抗凝固開始は「出血リスクが落ち着いてから」が原則。POAFの抗凝固は塞栓リスクと出血リスクを個別に天秤にかける（第II部1-6）。

1. 術後心房細動（POAF）★最重点

1-2. リスク因子（STS 2026）

  • 術前： 高齢、左房拡大、肥満、睡眠時無呼吸、左室収縮/拡張障害、既存の無症候性上室性不整脈、COPD、糖尿病、慢性腎臓病、β遮断薬の中断。
  • 術中： 人工心肺、大動脈遮断時間延長、術式の複雑さ。
  • 術後： 静注カテコラミンの使用、心膜液/血液の貯留。

2. 心房粗動・心房頻拍

  • POAFと連続的に扱われることが多く、レートコントロール・リズムコントロールの原則はPOAFに準じる。
  • JCS 2020（薬物治療）：
    • 血行動態安定の心房粗動 → IV/経口 ジルチアゼムまたはベラパミルでレートコントロール：COR I, LOE A。
    • 血行動態不安定の心房粗動 → IV ランジオロール：COR IIa, LOE B。
    • 症候性心房粗動の停止に IV アミオダロンまたはニフェカラント：COR IIa, LOE C（IVクラスIIIはNHI適応外の点に注意）。
    • 薬剤抵抗性/禁忌の術後遷延性粗動 → DC除細動：COR IIa, LOE C。
  • 切開瘢痕起源の心房内リエントリー頻拍は薬剤抵抗性のことがあり、難治例はカテーテルアブレーションが選択肢。

3. 発作性上室頻拍（AVNRT / AVRT）

  • 頻度は高くないが、規則的なnarrow QRS頻拍として術後にみられる。
  • 第一選択：迷走神経刺激 → アデノシン三リン酸（ATP）急速静注（第III部）。
    • 日本では海外のadenosineに代えて**ATP製剤（アデホス-Lコーワ注 等）**を急速ワンショット静注＋後押しフラッシュで使用。⚠️ PSVTは添付文書上の適応外。
  • ATP無効/再発例：ベラパミル（ワソラン静注）（第III部）。
  • WPW併存のAFには房室結節抑制薬（ジゴキシン・非DHP CCB・β遮断薬）を避ける（順行伝導促進の危険）。

4. 心室期外収縮・非持続性VT

  • 術後早期は高頻度。多くは良性だが、虚血（グラフト不全）・電解質異常（低K・低Mg）・カテコラミン過剰を評価。
  • まず是正可能な誘因の補正（K ≥4.0–4.5 mmol/L、Mg補正）。
  • 症候性/頻発例で器質的心疾患がある場合は β遮断薬。基礎心機能低下例ではクラスIC薬を避ける（JCS 2020）。

5. 持続性VT・VF・electrical storm

診断・初期対応

  • 血行動態不安定なVT/VF → 即時電気的除細動。術直後は第II部8（術後心停止プロトコル）に従う。
  • 必ず可逆的誘因（虚血/グラフト不全、タンポナーデ、電解質、低酸素、QT延長薬）を検索。

Electrical storm（24時間以内に3回以上の持続性VA：ESC 2022）

介入 ESC 2022
鎮静（軽度〜中等度） Class I, Level C
β遮断薬（非選択的が望ましい）＋IVアミオダロン Class I, Level B
同期電気的除細動 Class I, Level B
incessant VT/storm（SMVT, 薬剤抵抗性）へのカテーテルアブレーション Class I, Level B
難治例の機械的循環補助（MCS） Class IIb
アミオダロン抵抗性stormに ランジオロール 有効性の記載あり（narrative）

VT/VFへの抗不整脈薬（JCS 2020）

  • 電気的除細動後の持続性/反復性・血行動態不安定VT蘇生に IVアミオダロンまたはニフェカラント：COR IIa, LOE A。
  • 血行動態安定のmonomorphic持続性VTに IVプロカインアミド：COR IIa, LOE A。

6. Torsades de Pointes（TdP）/ QT延長

  • 誘因：QT延長薬（ソタロール、ベプリジル、一部の抗菌薬・制吐薬等）、低K・低Mg、徐脈。
  • 対応（ESC 2022）：
    • IVマグネシウム＋カリウム補充：Class I, Level C。
    • 心拍数を上げる（イソプロテレノール or overdrive 経静脈/心外膜ペーシング）：後天性LQTの反復TdPに Class I, Level C。
    • アミオダロン・ソタロールは禁忌（QTをさらに延長）。
  • 原因薬の中止とQT監視。

7. 徐脈性不整脈（洞機能不全・房室ブロック）と一時/恒久ペーシング

一次資料：ESC 2021ペーシングGL・JCS/JHRS 2019非薬物治療GL・HRS/APHRS/LAHRS 2023生理的ペーシングGL（いずれも本リポジトリ収載）。

発生・背景

  • 房室ブロック（AVB）は 心臓手術後の約14%、再弁手術後の約8% に生じる（ESC 2021）。洞機能不全（SND）は 右側房切開や経中隔上方アプローチ（僧帽弁手術） の後にみられる。
  • ペースメーカ植込みは CABGより弁手術後に多い（ESC 2021）。大動脈弁置換（石灰化重度・再手術）・三尖弁手術で頻度が高く、TAVI後の新規LBBB・高度AVブロックも臨床的に重要。

急性期対応

  • 一時心外膜ペーシングで即時対応（DDDで房室同期を維持）。
  • 薬物的ブリッジ：アトロピン（迷走神経性/症候性徐脈）、無効時 イソプレナリン（第III部）。JCS 2020：交感神経刺激薬またはアトロピンをペースメーカへのブリッジに COR IIa, LOE C。
  • 薬剤抵抗性で血行動態を損なう徐脈性不整脈には 一時経静脈ペーシング：ESC 2021 Class I, Level C。

恒久ペースメーカ（PPM）の判断 — 観察期間が鍵

推奨 格付け
術後の高度/完全AVB：少なくとも5日間の臨床観察を行い一過性か（回復するか）を評価。ただし補充調律が低/欠如で回復が見込めない完全AVBでは観察期間を短縮しうる ESC 2021：Class I, Level C
術後に回復が期待できない高度/完全AVB → 恒久ペースメーカ JCS 2019（表7）：COR I, LOE C
機械弁三尖弁置換後にペーシングを要する場合、経弁的RVリードは避ける ESC 2021：Class III, Level C
  • 補足（ESC 2021）：臨床的には通常 3–7日の観察。完全AVBが術後24時間以内に発生し48時間持続する場合は1–2週以内の回復が見込み薄く、早期植込みを考慮。一方で SND植込み例の60–70%・AVB植込み例の最大25%はフォロー時にペースメーカ非依存であり、過剰植込みに注意。

TAVI後の伝導障害（ESC 2021）

推奨 格付け

ペーシング様式

  • 高頻度の心室ペーシングが見込まれる場合は、ペーシング誘発心筋症の回避の観点から His束/左脚領域ペーシング・CRTを考慮（HRS/APHRS/LAHRS 2023）。
