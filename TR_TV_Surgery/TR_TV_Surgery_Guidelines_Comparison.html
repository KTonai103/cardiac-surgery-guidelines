1. TRの病態分類（一次性／二次性・心室性／心房性・CIED関連）

1-1. 一次性（器質性）TR vs 二次性（機能性）TR

分類 病態 主な原因
一次性 TR（器質性 / Primary TR：PTR） 三尖弁尖・腱索・乳頭筋自体の構造異常 感染性心内膜炎（IE）、外傷（胸壁外傷・心筋生検）、リウマチ性、粘液腫様変性（prolapse／flail）、Ebstein 奇形、カルチノイド症候群、放射線、薬剤誘発、先天性
二次性 TR（機能性 / Secondary TR：STR） 弁尖・腱索の構造は正常で、三尖弁輪拡大／RV テザリングによる接合不全 左心系弁膜症や HFrEF に伴う後毛細管 PH、肺動脈性 PH、慢性肺疾患、肺塞栓、心房細動、左心系弁手術後
CIED 関連 TR リードと弁尖／腱索／乳頭筋の機械的相互作用、リード関連線維化、RV pacing による dyssynchrony、リード抜去時の弁尖損傷 ペースメーカー、ICD、CRT のリード留置／抜去
二次性 TR の割合

JCS 2020：二次性 TR が全 TR の 70-90% を占める（一次性は 10-30%）。
ACC/AHA 2026：CIED-related TR を独立カテゴリとして区別（Table 1: Etiologic Classification of TR）。
ESC/EACTS 2025：解剖学的に明らかな TV 異常を有する一次性 TR は 8-10% のみで、大多数が二次性 TR。

1-2. 二次性 TR の表現型：心室性 vs 心房性（ESC/EACTS 2025 が明示）

ESC/EACTS 2025 Section 11.1 — 二次性 TR の2表現型
表現型 メカニズム 主な所見 典型背景
心房性 STR（atrial STR / A-STR） RA 拡大・三尖弁輪拡大が主体、leaflet tethering は軽度 RV サイズ／機能・肺動脈圧・LV 機能保持 持続性 AF、HFpEF
心室性 STR（ventricular STR / V-STR） 弁輪拡大 + leaflet tethering（RV 拡大に伴う） 左心系弁膜症／心筋疾患による後毛細管 PH、前毛細管 PH、原発性 RV 心筋症／虚血、左側弁手術後

進行期では両者は識別不能となり、現行の推奨は主に 一次性 vs 二次性 で構成される。

ACC/AHA 2026 も同じ概念を採用し、Ventricular Secondary TR（V-STR） と Atrial Secondary TR（A-STR） を Table 1 で明示的に区分。
JCS 2020 は AF に伴う annular dilatation を主機序とする TR と PH に伴う tethering を主機序とする TR を別個に議論（5.2.3 b. Isolated TR Associated With AF）。

1-3. CIED 関連 TR（ESC/EACTS 2025・ACC/AHA 2026 で重視）

CIED 関連 TR の分類
  • CIED-related causative TR：リードが TR の直接原因（弁尖・腱索・乳頭筋との機械的相互作用、リード関連線維化、RV pacing dyssynchrony、抜去時の弁尖損傷）
  • CIED-related incidental TR：CIED は存在するが TR の直接原因ではない

ACC/AHA 2026 は MDT に CIED specialist／電気生理医を必須メンバーに含める こと、また TTVR では新規 PPM 留置率 13-25% に達する ことから事前評価を強調。

3. 右室機能評価とリスク層別化

3-1. RV 機能評価の指標（3ガイドライン共通項目）

指標 正常下限／カットオフ 注意点
TAPSE（tricuspid annular plane systolic excursion） >16-17 mm（ACC/AHA、JCS）／重症 TR では基準下限を保守的に取る（ESC） 重症 TR では弁輪の longitudinal motion が誇張され RV 機能を過大評価
三尖弁輪収縮期速度（s′／TDI） >10 cm/s 重症 TR で偽性正常化あり
FAC（fractional area change） >35% 逆流血流が RA に流れるため過大評価傾向（LVEF と同じ問題）
RV 自由壁 longitudinal strain（FWS） より新しい指標。負荷条件依存性が低い 重症 TR の早期 RV 機能低下検出に有用
RVEF（CMR） >45% CMR が gold standard（JCS 4.4、ESC 11.2）
RV-PA coupling：TAPSE/SPAP 低値で予後不良 重症 TR・HF 全般での予後因子（ESC 11.2）
ESC/EACTS 2025 の RV 評価指針（Section 11.2）

「重症 TR では RV 機能が過大評価されやすいため、現行の echo 指標では最も保守的／厳格な閾値を採用 すべき」と明記。
正確な RV サイズ・機能・容量評価が意思決定上必須の場合は CMR を使用 すべき。

3-2. リスクスコア（ESC/EACTS 2025 が明示、ACC/AHA 2026 が運用化）

スコア 用途 構成因子 解釈
TRI-SCORE 重症 TR の周術期／中期予後予測 NYHA、利尿薬投与量、eGFR、ビリルビン、LVEF、PASP、RV 機能、性別、AF ≤3：低リスク、4-5：中リスク、≥6：高リスク（手術での生存利益なし）
STS isolated TV risk calculator 単独 TV 手術のリスク予測 外科リスク因子 周術期死亡・主要合併症の予測
TRIVALVE score TTVI（T-TEER／TTVR）の1年死亡・HF 入院予測 5変数 TTVI 適応判定の補助
ESC/EACTS 2025 が引用するレジストリ解析（n=2413）
  • TRI-SCORE ≤5（低／中リスク）：早期 TV 介入（外科または経カテーテル）で中期生存改善
  • TRI-SCORE ≥6（高リスク）：介入と保存治療で差なし → futile intervention のリスクあり
  • TRI-SCORE ≤3（低リスク）：単独 TV 手術が10年生存改善
  • TRI-SCORE 4-5（中リスク）：TV 修復成功例のみで同等の生存利益

3-3. RV 機能・PH の「介入禁忌／futile」閾値（ESC/EACTS 2025）

介入を控えるべき「進行期」サイン
  • 重症 LV/RV 機能低下
  • 重症 pre-capillary PH
  • 不可逆な肝硬変（JCS 4.4、ESC 11.2）
  • 進行した cachexia・全身状態不良

これらが揃った時点では、外科・経カテーテル介入とも周術期リスクが極めて高く、保存治療と同等の予後にとどまる可能性が高い（"too late to fix"）。

4. 一次性TRの介入適応

4-1. 一次性 TR の主要適応（JCS 2020 Table 37、ESC/EACTS 2025 Recommendation Table 9、ACC/AHA 2020）

推奨事項 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
重症一次性 TR + 左側弁手術同時施行 Class I, Level B Class I, Level B（一次性／二次性とも） Class I, Level B-NR（Stage C/D）
症候性重症一次性 TR（孤立性／単独手術） Class I, Level C（薬物治療不応の右心不全） Class I, Level C（重症 RV 機能低下・重症 PH なし） Class IIa, Level B-NR（Stage D）
無症候性重症一次性 TR + 進行性 RV 拡大／機能低下 Class IIa, Level C Class IIa, Level C（重症 LV/RV 機能低下・重症 PH なし） Class IIb, Level C-LD（Stage C）
3ガイドライン共通の基本骨子
  • 重症一次性 TR で左心系弁手術が必要 → 同時 TV 介入を Class I（最も強い推奨）
  • 重症症候性一次性 TR（薬物不応）→ TV 介入を Class I（JCS・ESC）または IIa（ACC/AHA）
  • 無症候性でも RV 拡大／機能低下が進行性 → 早期介入を考慮
差異ポイント① — 症候性重症一次性 TR の推奨強度

JCS と ESC は Class I, Level C で外科治療を強く推奨するのに対し、ACC/AHA 2020 は Class IIa, Level B-NR とやや控えめ。これは ACC/AHA が「外科介入の長期 durability が不確実」「至適タイミング未確立」という慎重姿勢を反映している。

4-2. 一次性 TR の代表的病態と外科治療上の特殊配慮

病態 配慮
感染性心内膜炎（IE）由来 急性期も外科適応あり。詳細は感染性心内膜炎 GL を参照
Ebstein 奇形 弁形成（cone reconstruction）を経験施設で。負荷時 CO の改善を運動負荷 echo で評価可（JCS 4.2.3、Class IIb）
外傷性 flail（胸壁鈍的外傷） 比較的若年・健常で手術リスク低い → 早期介入推奨（ACC/AHA）
CIED リード由来の一次性 TR リード抜去・repositioning の検討（電気生理医との協議）、TR が rapid に進行するため早期介入（ACC/AHA）
カルチノイド 安定した oncological 状況が前提（ESC 12.4）
リウマチ性 多くは MV 病変と合併。形成術困難で TVR が多い

5. 左心系弁手術時の三尖弁同時介入（重要）

本セクションはユーザーから明示的に依頼された主要テーマ。

5-1. 重症 TR + 左心系弁手術：3ガイドライン共通の Class I

推奨事項 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
重症 TR（一次性／二次性とも）+ 左側弁手術同時施行 一次性 Class I, Level B（Table 37）・二次性 Class I, Level C（Table 38） Class I, Level B（Rec Table 9） Class I, Level B-NR（Stage C/D）
共通根拠
  1. 重症 TR は左側弁手術単独では改善しないことが多い
  2. isolated TR への再手術は周術期死亡 10-25% と極めて高リスク（ACC/AHA、JCS）
  3. 同時 TV 修復は手術リスクを有意に増加させない（JCS、ESC：retrospective／RCT エビデンスから）
  4. 早期介入で RV reverse remodeling が得られる

5-2. 中等度 TR + 左心系弁手術：地域差あり

推奨事項 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
中等度二次性 TR + 左側弁手術 Class IIa, Level C（Table 38）— 弁輪拡大の有無にかかわらず Class IIa, Level B（Rec Table 9）— TR 進行・RV remodeling 予防 （明示的 Class なし、ステージ B として個別判断）
ESC/EACTS 2025 の根拠

2件の RCT（2024年発表）と大規模後ろ向き研究で、中等度 TR への annuloplasty が TR 進行・RV remodeling を抑制することが確認された。

6-3. 弁輪拡大評価の実務的論点

CQ4（JCS 2020）— 弁輪拡大単独で annuloplasty を推奨できるか？

結論：2C（弱く推奨／提案）。理由：

  • 単一 RCT（Benedetto 2012）のみが「40 mm or 21 mm/m²」を直接検証
  • 観察研究は heterogeneity（術式・選択バイアス・MVR vs MVRpair）が大
  • MVR では弁輪径によらず TR 進行率高く、Stage B でも annuloplasty を考慮可
  • 弁輪拡大に加え AF、RV 機能低下、LA 拡大、PASP 上昇など複数因子併存例で利益が大きい
実臨床での意思決定（3ガイドライン統合）
  1. 同時 annuloplasty を「default」と考える：弁輪 >40 mm or >21 mm/m² なら軽度 TR でも実施を Default に
  2. TR 進行のリスク因子を加重：persistent AF、RV 拡大、PH、MVR 予定、LA 拡大、prior right HF symptom
  3. PPM 必要率（~14%）のリスクを balanced：高齢者・既存伝導障害は注意
  4. MV 手術形式が MVR か MVRpair かを考慮：MVR では TR 進行率が高く、より積極的な同時 TR 介入が合理的（JCS CQ4）

10-5. RV reverse remodeling と介入のタイミング

「Reverse remodeling」の期待される条件
  • 重症 TR を moderate 以下に低減できれば、RV サイズ・機能の reverse remodeling が期待できる（TRILUMINATE、TRI.Fr、TRISCEND II の核心エビデンス）

  • 逆に 重症 RV 機能低下が確立した時点では reverse remodeling 困難

14. まとめ・総括

共通事項

3ガイドライン共通の合意事項
  1. 重症 TR（一次性／二次性とも）+ 左側弁手術 → 同時 TV 介入は Class I（最も強い推奨）
  2. 三尖弁輪 ≥40 mm or >21 mm/m² は介入閾値の指標（カットオフは1996/2005年文献に由来）
  3. 形成術（annuloplasty ring）が置換術より優先（解剖適合例）
  4. 重症 TR では echo の RV 指標が過大評価：CMR を gold standard、保守的閾値の採用
  5. 進行 RV 機能不全・重症 PH・不可逆肝障害・cachexia では介入から利益少（"too late to fix"）
  6. 既往左側弁手術後の孤立性 TR 再手術は高リスク（周術期死亡 10-25% → 早期介入の重要性）
  7. AF 関連二次性 TR は他の STR と病態が異なる（RA・弁輪拡大主体、RV elongation 軽度）
  8. CIED 関連 TR は別個に評価（lead extraction、repositioning、epicardial system 検討）
  9. 左側病変が改善しても重症 TR は自然軽快しないことが多い → 同時介入の根拠
  10. Heart Team / 弁膜症チーム評価が前提

臨床的含意

地域別アプローチの特徴
  • 🇪🇺 欧州（ESC/EACTS 2025） は (1) 経カテーテル TV 治療を Class IIa, Level A に格上げ（TRILUMINATE・TRI.Fr・TRISCEND II メタ解析）、(2) 無症候性重症二次性 TR + 進行性 RV 機能低下を Class IIa に格上げ、(3) 中等度 TR への同時 annuloplasty を Class IIa, Level B に格上げ（2024 RCT 根拠）、(4) V-STR vs A-STR の表現型分類を明示、(5) TRI-SCORE による患者層別と "futile" の概念を明示、(6) Massive/Torrential を含む5段階分類 という6点で最も積極的・体系的。Heart Valve Centre / Heart Team / 個別解剖評価を重視。
  • 🇺🇸 米国（ACC/AHA 2020・2026） は A〜D ステージ分類による明確な患者層別が特徴で、(1) 軽度 TR + 弁輪 ≥40 mm への annuloplasty を Class IIa（最も積極的）、(2) AF 関連 TR の独立した pathophysiology を明示、(3) 2024 FDA 承認後の TriClip／EVOQUE 運用文書（2026 operator/施設要件）を最も詳細に規定、(4) CIED-related TR を独立カテゴリ化 が独自の強い特徴。一方で 症候性重症一次性 TR への手術 は Class IIa と他より控えめ。
  • 🇯🇵 日本（JCS 2020） は (1) TR を AF 関連・PH 関連・左側弁手術後で独立した isolated 介入として扱う構成、(2) Figure 18-20 と Table 37-39 の明確な意思決定アルゴリズム、(3) CQ4 として「弁輪 ≥40 mm のみで軽度 TR への annuloplasty を強く推奨できるか」を批判的に検証、(4) 日本人体格（小柄）における 21 mm/m² カットオフの検証不足を明記、(5) 不可逆肝機能障害（ICG、Child-Pugh、MELD）への配慮、(6) 経カテーテル治療への期待は限定的（2020時点で本邦未承認） が特徴。重症度分類は伝統的な3段階を維持。

実臨床での意思決定フレームワーク

TR 介入の意思決定アルゴリズム（3ガイドライン統合）

Step 1：TR を一次性 vs 二次性 vs CIED 関連に分類（弁尖の器質的異常・CIED リードとの相互作用の有無）

Step 2：二次性なら 心室性 vs 心房性 に分類（ESC 11.1 / ACC/AHA 2026 Table 1 を参照）

Step 3：重症度を多指標で integrative assessment（VC・EROA・RVol・jet area・肝静脈・CW shape）。重症 TR では echo 過小評価注意、CMR / Fick CO 検討

Step 4：RV 機能・PH を保守的に評価（TAPSE・FAC・s′・RV FWS・TAPSE/SPAP、必要なら CMR）

Step 5：「Futile」評価（TRI-SCORE ≥6、不可逆肝障害、cachexia、重症 RV/LV 機能低下、重症前毛細管 PH）→ 該当すれば保存治療／緩和ケア

Step 6：症状・左側弁手術の必要性で判断

  • 重症 TR + 左側弁手術：同時 TV 介入 Class I（3 GL 共通）
  • 中等度 TR + 左側弁手術：同時 annuloplasty 考慮（ESC IIa-B、JCS IIa-C）
  • 軽度 TR + 弁輪 ≥40 mm or >21 mm/m² + 左側弁手術：ACC/AHA IIa-B、JCS/ESC IIb で考慮
  • 症候性重症一次性 TR（孤立性）：手術（JCS/ESC I-C、ACC/AHA IIa-B-NR）
  • 症候性重症二次性 TR（孤立性）+ 薬物不応：手術（3 GL とも IIa）または 経カテーテル TV 治療（ESC IIa-A）
  • 無症候性重症 TR + 進行性 RV 機能低下／拡大：早期介入考慮（ESC が最も積極的）

Step 7：外科 vs 経カテーテル

  • 外科：低-中リスク（TRI-SCORE ≤5）、形成 first（annuloplasty ring）
  • 経カテーテル：高外科リスク・症候性重症 TR・QOL 改善目的（ESC IIa-A、ACC/AHA 2026 運用文書）
  • 既往心臓手術後の重症 TR：経カテーテル治療が魅力的選択肢

Step 8：CIED 関連 TR は電気生理医と協議（lead extraction、repositioning、epicardial system、leadless/coronary sinus pacing 検討）
