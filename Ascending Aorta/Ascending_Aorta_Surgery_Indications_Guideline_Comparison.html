Part I: 各ガイドラインの概要と推奨

I-1. JCS 2020 大動脈瘤・大動脈解離診療ガイドライン (JCS 2020 Ao)

概要

  • 正式名称: 2020年改訂版 大動脈瘤・大動脈解離診療ガイドライン
  • 発行団体: 日本循環器学会 / 日本心臓血管外科学会 / 日本胸部外科学会 / 日本血管外科学会（合同ガイドライン）
  • 発行年: 2020年（2024年8月更新）
  • 班長: 荻野 均（東京医科大学 心臓血管外科学分野）
  • スコープ: 大動脈疾患全般（大動脈瘤・大動脈解離の定義、病態、疫学、検査、内科治療、血管内治療、外科手術、遺伝性大動脈疾患、BAV aortopathy、リハビリテーション、サーベイランス）
  • 上行大動脈の位置づけ: 第5章「大動脈瘤の治療」1.2節「非破裂性胸部大動脈瘤」内に「1.2.1 大動脈基部・上行大動脈瘤」として独立小節（表12）。第8章に遺伝性大動脈疾患（1節）とBAV aortopathy（2節）を独立章で記載

推奨クラス・エビデンスレベル体系

クラス 定義
I 手技・治療が有効・有用であるというエビデンスがあるか、見解が広く一致
IIa エビデンス・見解から有用・有効である可能性が高い
IIb 有用性・有効性がそれほど確立されていない
III 有効でなく、ときに有害であるとのエビデンスがあるか、見解が広く一致
レベル 定義
A 複数のRCTまたはメタ解析
B 単一のRCTまたは大規模非ランダム化研究
C 専門家の意見、小規模臨床試験、後ろ向き研究

推奨内容 クラス レベル
無症状・弁手術適応なし：大動脈基部・上行大動脈径 >=55mm I C

弁手術/他の開心術時：>=45mm で併施 IIa C

Loeys-Dietz症候群

  • Marfan症候群より上行大動脈径が小さい値で解離・破裂が生じるとの記載（クラスIIa、レベルC）
  • 遺伝子別の径閾値は設定されていない。TGFBR1/TGFBR2変異をMarfanの閾値引き下げ因子として位置づけ

Turner症候群

  • 大動脈径係数 (ASI) >2.5 cm/m2 で大動脈置換術を検討（本文記載）
  • 大動脈解離の発症率は対照の100倍

JCS 2020 Ao の特徴

  1. 拡大速度: >=5mm/半年 を手術適応（クラスI）としており、ACC/AHA（>=0.5cm/年 or >=0.3cm/年×2年連続）やESC（>=3mm/年をRF扱い）と基準が異なる
  2. 低い閾値での手術考慮: リスク因子あり >=45mm（IIa）、40-45mm（IIb）と、欧米より積極的に閾値引き下げを設定
  3. 妊娠前Marfan: >=40mm でIIa推奨（欧米は >=45mm がClass I）
  4. 施設裁量の重視: 「ガイドラインは診療内容を規定するものではなく、実際の診療はあくまで施設や医師ごとの判断に委ねられる」と明記
  5. 熟練した施設と50mm閾値: 以下の2経路で推奨表に明記されている（「本文のみ」は誤り）
    • 表12（IIa, C）: 「大動脈解離の家族歴を有し、拡大速度≥5mm/半年、手術リスクが低い症例においては、熟練した施設で行うことを推奨し、最大径≥50mmで手術を考慮する」— 推奨クラスとして推奨表本体に記載
    • 表52 BAV（IIa, C）: 危険因子あり＋上行≥50mm → 推奨表に明記
    • 表52 BAV（IIb, C）: 危険因子なし＋上行50mm → 推奨表に明記
    • 本文 2.2.1節: 「BAVの後ろ向き観察研究では径が53mm以上で解離・急性大動脈症候群のリスクが高まったことから、大動脈治療の経験値が高い施設での適応が可能である」（53mm hinge point文脈、"可能"という表現）
    • ⚠️ 孤発性TAV（遺伝性素因なし・急速拡大なし）には非適用: PQ7推奨文が「遺伝性大動脈疾患がない場合は大動脈径≥55mm」と明記。表12 IIaの「家族歴＋急速拡大≥5mm/半年」条件は実質的にnsHTAD（家族性胸部大動脈瘤）に相当し、真の孤発性TAVとは区別される。ACC/AHA 2022がExpert施設条件のみで孤発性TAVに50mmを適用できるのと対照的な相違点

径の測定方法

  • CT/MRIで大動脈長軸に直交する断面の長径・短径を計測
  • 蛇行部位ではMPR像の作成を推奨、設備がない場合は最大短径を指標
  • 内径vs外径の明確な規定はなし

I-2. JCS 2020 弁膜症治療のガイドライン (JCS 2020 VHD)

概要

  • 正式名称: 2020年改訂版 弁膜症治療のガイドライン
  • 発行団体: 日本循環器学会 / 日本胸部外科学会 / 日本血管外科学会 / 日本心臓血管外科学会
  • 発行年: 2020年
  • 班長: 泉 知里（国立循環器病研究センター）、江石 清行（長崎大学）
  • スコープ: 弁膜症全般。AR章の第6節「上行大動脈拡大・特殊例に対する手術適応」に大動脈関連記載
  • 推奨体系: JCS 2020 Aoと同一。CQについてはMinds 2014の方法論（推奨の強さ「1」「2」、エビデンス総体A-D）も採用

JCS 2020 VHD の特徴

  1. TAV単独手術のクラス差: Aoガイドライン（55mmでクラスI）に対し、VHDガイドラインは55mmでクラスIIa。Aoは症状ありの瘤を含む記載のため文脈差
  2. TAV弁手術併施時の閾値差: Aoガイドライン：45mm、VHDガイドライン：50mm。5mmの乖離あり
  3. 拡大速度の表現差: Aoは「>=5mm/半年」（10mm/年相当）、VHDは「>5mm/年」と実質的に異なる閾値
  4. 体格補正への言及と保留: 「欧米人に比較的体格の小さい日本人」への配慮の必要性に言及しつつ、「基準値に関してはエビデンスがなく、本ガイドラインでは明記しない」と明確にエビデンス不足を認める
  5. Heart Valve Team: Expert施設による閾値引き下げの記載はなし。高リスク例でのチーム判断を推奨するのみ

15. 臨床上の注意点

総合的留意事項
  1. 径の測定方法: ガイドラインにより推奨される測定法が異なる（inner edge vs outer edge、leading edge to leading edge、心電図同期の有無）。ESC 2024はinner-to-inner、EACTS/STS 2024はouter-to-outerを推奨し、同時期の欧州ガイドライン間で不一致がある。比較時には測定法の統一が重要。
  2. エビデンスの限界: 全ガイドラインにおいて予防的手術のRCTは存在せず、推奨は観察研究と専門家合意に基づく。
  3. 個別化: 全ガイドラインが、径のみでなく拡大速度、家族歴、遺伝子型、体格、手術リスク、患者希望を含めた総合判断を推奨している。
  4. Expert施設の定義の曖昧さ: ACC/AHA 2020 VHDの "Comprehensive Valve Center" を除き、大部分のガイドラインは "experienced center" の具体的定義（症例数要件等）を提示していない。ACC/AHA 2022 Aoのみ年間30-40例以上のvolume基準に言及。
  5. Root vs Ascending phenotype: ESC 2024/EACTS/STS 2024が導入したphenotype分類は手術閾値に影響し、root phenotypeでは55mmではなく50mmでの手術が考慮される。
  6. 大動脈長: ESC 2024/EACTS/STS 2024が導入した新概念。>=11cmは急性大動脈イベントのリスク因子として位置づけられ、径の閾値引き下げを支持する。
