1. 概要：本文書のスコープと「冠血行再建ガイドライン群」の構造

1-1. 本文書のスコープ

対象範囲

本文書は 成人の冠動脈疾患に対する血行再建（CABG／PCI） の適応・術式・周術期管理に関する各地域ガイドラインの横断比較である。

  • 一次予防／脂質管理／β遮断薬／RAAS 阻害薬の詳細はカバーしない（本文の範囲外）
  • 急性心筋梗塞後の心不全管理は重症 LV 機能不全と LVAD・移植への橋渡しの文脈でのみ言及
  • 小児・先天性冠動脈異常／川崎病冠動脈瘤・冠動脈攣縮性狭心症の専門領域は範囲外
  • 経カテーテル僧帽弁・三尖弁治療は MR 比較・TR 比較 を参照

主要な対立軸（本比較の見どころ）
  1. 3枝病変・LV 機能正常での CABG 推奨：ACC/AHA 2021 で Class 2b（「妥当性あり」） に格下げ → AATS/STS が公式に異議。ESC 2024 は Class I, A を維持。
  2. LM 高 SYNTAX (≥33) での PCI：ESC 2018 III B → ESC 2024 IIb B（外科ハイリスク前提）に緩和。ACC/AHA 2021 は Class 1 B-R で CABG を選択 と明示。
  3. 橈骨動脈の位置づけ：ACC/AHA 2021 で Class 1, B-R（vs SVG, second target） に格上げ。STS 2016 は IIa B、ESC 2024 は専用推奨を 2018 GL に委任。
  4. STEMI 完全血行再建：ESC 2023 I A（45 日以内）、ACC/AHA 2025 Class 1 A（staged）。両者は COMPLETE／FULL-REVASC／MULTISTARS-AMI を反映し統一方向。
  5. 心原性ショックでの microaxial pump（Impella）：ACC/AHA 2025 で Class 2a B-R に新規昇格（DanGer-SHOCK）。ESC 2023 は IIb C、JCS 2018 は記載不十分。
  6. VA-ECMO の routine 使用：ACC/AHA 2025 で Class 3: No Benefit（ECLS-SHOCK） に下方修正。
  7. CULPRIT-SHOCK：3ガイドラインで一致し、ショック合併 STEMI で responsible 以外の routine PCI は推奨されない（ESC IIb / ACC/AHA Class 3: Harm）。

STEMI における緊急 CABG（表 31）

推奨 クラス LoE
PCI 不成功／技術的困難で、薬物抵抗性の不安定血行動態（CS や致死性不整脈）を呈する患者にハートチームで協議し緊急 CABG I C
  • 機械的合併症（VSP・自由壁破裂・乳頭筋断裂による急性 MR）に緊急修復を要する場合、同時 CABG を考慮
  • 発症 48 時間以内の急性期緊急 CABG は成績不良。それ以降は通常待機手術と同等の報告
  • 内胸動脈グラフトは血行動態安定例なら緊急 CABG でも剥離して使用可

  • メタ解析（ISCHEMIA を組み込む）で CABG vs 至適薬物療法の生存利益が縮小
  • 旧来の根拠データ（VA Cooperative、CASS、ECSS）は 20–40 年前の現代的薬物療法以前

反発と論争：

  • AATS／STS（米国胸部外科学会・胸部外科医学会） が公式に異議を表明
  • ガイドライン執筆委員会自身が "After several hours of deliberation" と長時間の議論を明記
  • 委員会の論理：完全比較 RCT は現代では unfeasible。CABG にはイベント抑制（Section 7.3 Class 2a）の利益が別途あるため、生存改善目的でなくとも CABG は推奨可能
  • 後年（2023–2024）に CTSNet 等で外科医側からの撤回要求あり、AHA/ACC が追加コメント文書を発行

10. ⭐ CABG vs PCI モード選択：左主幹部病変の比較

10-1. 主要推奨の並列表

病態 🇯🇵 JCS 2022（一般原則） 🇪🇺 ESC 2024 CCS 🇺🇸 ACC/AHA 2021
LM 全般 LMCA 病変は血行再建（I, B）／詳細は 2018 血行再建 GL に委任 外科リスク低の有意 LM 狭窄に CABG（I, A）／CABG は preferred mode（I, A） LM 狭窄に CABG（1, B-R）
LM 低 SYNTAX (≤22) （詳細は 2018 GL） PCI is recommended as alternative（I, A） LM + PCI が同等の血行再建可能なら PCI is reasonable（2a, B-NR）
LM 中等度 SYNTAX (23–32) （詳細は 2018 GL） PCI should be considered（IIa, A） LM + PCI が同等の血行再建可能なら PCI is reasonable（2a, B-NR）

10-2. 含意

  • LM 病変全般で CABG が生存改善目的の標準 という点で 3 ガイドライン一致
  • LM 低〜中等度 SYNTAX での PCI 代替は ESC 2024 が最も明示的（Class I A／IIa A）、ACC/AHA 2021 は単一クラス（2a, B-NR）でカバー
  • LM 高 SYNTAX（≥33） での扱いに最大の地域差：ACC/AHA は明確に CABG 優位（Class 1）、ESC 2024 は「外科ハイリスクならば PCI も IIb で許容」と相対化
  • 旧 ESC 2018 GL の LM 高 SYNTAX → PCI: Class III B という強い禁忌は 緩和（IIb B）された
  • 主要試験：EXCEL（LM-PCI vs CABG、3 年複合エンドポイント同等／5 年で死亡 PCI 群やや増、SCAI 定義の MI で見解相違）、NOBLE（LM-PCI で 5 年 MACCE は CABG より劣る）、SYNTAX（LM サブグループは PCI 同等）
LM 病変の核心

ESC 2024 は EXCEL／NOBLE の意見分裂を踏まえ、**「PCI が CABG と同等の completeness を提供できる場合のみ」**を条件として PCI を選択肢化。ACC/AHA 2021 も同様の条件で 2a を付与。高 SYNTAX では CABG が依然標準。EXCEL の SCAI 定義 vs WHO/UDMI 定義の MI 判定問題は両者で言及されるが、結論には影響していない。

  • 日本の JCS 2018 血行再建 GL の伝統的立場は ESC に近く、3 枝病変は CABG を念頭においた SDM
  • 臨床現場では、ISCHEMIA を「症状とリスク評価を踏まえた個別判断の根拠」と取るか、「血行再建全般の利益縮小の証拠」と取るかで姿勢が分かれる
  • AATS／STS は ISCHEMIA の解釈に異議：(1) 平均 5.6 年フォロー、(2) SYNTAX 高複雑度患者・LM 患者除外、(3) CABG 群が 25% にとどまる、(4) cross-over 多、(5) 自然発生 MI 抑制効果（CABG）は捕捉

23-2. ⭐ 心臓外科医の臨床判断ポイント（Take-Home）

心臓外科医のための要点
  1. 3 枝病変・LV 機能正常の患者では「ACC/AHA 2021 Class 2b」を理由に CABG を諦めない。ESC 2024 は Class I、AATS/STS は ACC/AHA 2021 の格下げに異議。Heart Team で「自然発生 MI 抑制」「再血行再建率低下」を CABG 利益として提示。
  2. 糖尿病 + 多枝病変は世界一致で CABG (LIMA-LAD)。Heart Team で第一選択として提示。
  3. 左主幹部高 SYNTAX (≥33) は CABG が標準。低〜中等度 SYNTAX のみ PCI を代替検討。
  4. 重症 LV 機能不全 + MVD では CABG が STICH 10 年延長で生存改善。LVEF ≤35% でも CABG 適格性を慎重評価し、放置や PCI で代替しない。手術不能例で LVAD／心臓移植検討。
  5. 橈骨動脈は SVG より優先（ACC/AHA 2021 Class 1）。少なくとも 2 本目グラフトとして検討。BITA は経験者の適切な患者で（Class 2a）、skeletonized harvest 必須。
  6. STEMI 緊急 CABG は限定的だが、機械的合併症・CS・PCI 不可解剖では Class I。緊急 CABG の場合も血行動態安定なら LIMA-LAD 使用。発症 48 時間以内は成績不良なので、可能なら数日経過後。
  7. AMI 機械的合併症（VSR）は 1–2 週間の待機が日本ではコンセンサス。LVAD 長期 bridge で段階的治療の可能性。同時 CABG は Class I C（ESC）。
  8. CABG 前 P2Y12 休薬：クロピドグレル 5 日／プラスグレル 7 日／チカグレロル 3–5 日（3 地域統一）。緊急例は 24 時間中断を最低限。
  9. CABG 後 aspirin lifelong（I, A）。グラフト閉塞高リスク・出血低リスクで CABG 後 DAPT を考慮（IIb, B）。
  10. Heart Team は安定 CAD・複雑病変・機械的合併症・CS で必須。STS-PROM 算出は CABG 前に I レベル。

23-3. ⭐ ガイドライン進化の方向性

  • エビデンスベース → エビデンスとリアルワールドの調整：ACC/AHA 2021 の 3VD 格下げは ISCHEMIA の解釈をめぐる学会間対立を露呈。ESC 2024 は伝統的 CABG 優位を維持
  • 新規 RCT の影響：DanGer-SHOCK／ECLS-SHOCK／COMPLETE／MULTISTARS-AMI／REVIVED-BCIS2 が短期間で複数推奨を書き換え
  • CABG 手技推奨は STS／EACTS が学会レベルで主導。総合 GL（ACC/AHA・ESC）は手技詳細を専門学会に委任する傾向
  • 日本独自のデータ蓄積（REAL-CAD・PRASFIT・本邦冠攣縮性狭心症高頻度） が JCS 推奨の独立性を支える基盤
  • 次の改訂サイクル：ESC 心筋血行再建 GL（2018 → 2026 予定）、ACC/AHA 冠動脈血行再建 GL（次回改訂）で、ISCHEMIA／DanGer-SHOCK／REVIVED-BCIS2 の解釈収斂が焦点

23-4. 残された臨床的議論点

  1. ISCHEMIA 後の血行再建の位置づけ：症状改善目的の意義／自然発生 MI 抑制の重み付けが未収斂
  2. EXCEL／NOBLE の MI 定義論争：LM-PCI の長期成績評価で MI 判定基準（SCAI vs WHO/UDMI）が結論に影響
  3. CABG 後 DAPT のグラフト開存・心事故への影響：複数試験あるが Class IIb にとどまる
  4. Hybrid CABG/PCI：技術的に成熟しつつあるが RCT 不足、明確な推奨なし
  5. 重症 LV 機能不全 + MVD で CABG vs LVAD vs 心臓移植：CABG 適格性判定と STS-PROM 閾値の標準化
  6. AMI 機械的合併症の最適タイミング・MCS bridge 戦略：RCT 不能、観察研究中心
  7. 日本人 ACS の出血／血栓リスクプロファイル：欧米 DAPT 推奨そのまま導入の妥当性検証
  8. PCI 時代の冠攣縮性狭心症評価：日本人の高頻度（約 40%）に対する欧米モデルの適用限界
