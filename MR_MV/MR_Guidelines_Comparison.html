1. MRの病態分類（一次性・二次性／Carpentier分類）

1-1. 一次性（器質性）MR vs 二次性（機能性）MR

分類 病態 主な原因
一次性 MR（器質性 / Primary・Degenerative MR：PMR） 弁尖・腱索・乳頭筋自体の構造異常により MR が生じる 僧帽弁逸脱症（FED / Barlow's disease）、リウマチ性、IE、心筋梗塞による乳頭筋断裂、先天性、放射線、外傷
二次性 MR（機能性 / Secondary MR：SMR） 弁構造は概ね正常で、左室または左房の拡大・機能不全による MR 虚血性心筋症、拡張型心筋症（心室性 SMR）／心房細動・HFpEF に伴う左房・弁輪拡大（心房性 SMR）
3ガイドライン共通の枠組み

「一次性 vs 二次性」の分類は3ガイドラインで一致。さらに 二次性 MR を「心室性（ventricular SMR）」と「心房性（atrial SMR）」に分ける 二分概念は、ESC/EACTS 2025 と JCS 2020 が明示し、ACC/AHA 2020 も独立項目として記載している。

1-2. Carpentier 機能分類（JCS 2020 表8 を基準）

型 弁尖運動 代表的病態 典型的成因
Ⅰ型 正常 弁輪拡大・弁穿孔 心房性 SMR（弁輪拡大）、IE 穿孔
Ⅱ型 過剰（逸脱） 弁尖逸脱・腱索断裂 FED、Barlow's disease、乳頭筋断裂
Ⅲa 型 収縮期・拡張期ともに制限 弁尖肥厚・癒着 リウマチ性、加齢性硬化、放射線
Ⅲb 型 収縮期のみテザリング 弁尖が左室側に引かれる 心室性 SMR（虚血性／DCM）、後尖 hamstringing（心房性 SMR の合併）

1-3. 一次性 MR の病理形態（FED / Barlow Spectrum）

JCS 2020 図5（Adams DH 2010）の概念

弁尖組織の余剰度に応じた連続スペクトラム：FED ＜ FED+ ＜ Forme fruste ＜ Barlow's disease。

  • FED（fibroelastic deficiency）：腱索の変性による断裂・延長が主体、弁尖の余剰は少なく逸脱は限局的
  • Barlow's disease：弁尖自体の粘液腫様変性が広範、billowing が広く複数 jet を呈する 　→ 修復難易度・術式選択に直結（FED 系は posterior leaflet repair が中心、Barlow は extensive repair が必要で Comprehensive/Heart Valve Center で施行すべき）

2-1. JCS 2020（表10）— 3段階分類

下流ジェット面積 小、短時間 — 大きなセントラルジェット（>左房面積50%）
縮流部幅（VC, cm） <0.3 0.3〜0.69 ≥0.7
PISA法 EROA（cm²） <0.20 0.20〜0.39 ≥0.40
逆流量 RVol（mL） <30 30〜59 ≥60
逆流率 RF（%） <30 30〜49 ≥50
肺静脈血流 — — 収縮期陽性波消失、逆流波

JCS が明記する評価の落とし穴
  • 機能性 MR では PISA 法・縮流部幅単断面・PISA法EROA・逆流量は過小評価しやすい（楕円・横長 ERO）→ volumetric 法を優先
  • AR 合併例では volumetric 法は不正確
  • 偏位ジェット（Coanda効果）はカラードプラ法で過小評価
  • 低心拍出量の機能性 MR では逆流率と逆流量が乖離（逆流率は大、逆流量は小）

2-2. ESC/EACTS 2025 — PMR vs SMR で重症度閾値が異なる

パラメータ 一次性 MR（PMR） 二次性 MR（SMR）
EROA（cm²） ≥0.40 ≥0.30（より低い閾値）
逆流量 RVol（mL） ≥60 ≥45
SMR で閾値が低い理由

楕円形 ERO・低流量状態・横長 ERO のため、PMR と同じ閾値では SMR の予後インパクトを過小評価してしまう（参考：ESC 2025、Grayburn PA 2019、COAPT/RESHAPE-HF2）。

2-3. ACC/AHA 2020（表17・18）— A〜Dステージ分類

表17：慢性一次性 MR のステージ

ステージ 弁形態 弁血行動態 血行動態の影響 症状
A（At risk） 軽度逸脱、軽度肥厚、正常接合 jet なし or 中心性 jet 面積 <20% LA / VC <0.3 cm なし なし
B（Progressive） 中等〜高度逸脱、リウマチ性変化、IE 既往 jet 20〜40% LA、VC <0.7 cm、RVol <60 mL、RF <50%、ERO <0.40 cm² 軽度 LA 拡大、肺圧正常 なし

C2（無症候性重症 + LV機能低下） 同上 同上 LVEF ≤60% かつ/または LVESD ≥40 mm なし
D（症候性重症） 同上 同上 中〜高度LA拡大、LV拡大、肺高血圧 労作時呼吸困難・運動耐容能低下

表18：慢性二次性 MR のステージ（SMR）

ステージ 弁形態 弁血行動態 関連心所見 症状
A（At risk） 正常弁尖 jet なし 局所壁運動異常、LV拡大／収縮能低下 虚血・HF症状あり得る
B 弁尖の軽度テザリング、弁輪軽度拡大 ERO <0.40 cm²†、RVol <60 mL†、RF <50% 局所壁運動異常 + LV収縮能低下 虚血・HF症状あり得る

D 同上 同上 同上 再血行再建・最適内科治療後も MR による HF 症状残存
ACC/AHA が記載する SMR 評価の留意点

† 2D PISA は SMR の真の ERO を過小評価する（crescentic な近位収束のため）。これは ESC が SMR で閾値を下げている根拠と整合する。

2-4. 3ガイドライン重症度閾値の対照

基準 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
重症 EROA（PMR） ≥0.40 cm² ≥0.40 cm² ≥0.40 cm²
重症 EROA（SMR） 同上（PMRと共通） ≥0.30 cm²（低閾値） ≥0.40 cm²†（同表記、ただし PISA 過小評価あり）
重症 RVol（SMR） 同上 ≥45 mL ≥60 mL‡
分類体系 3段階（軽・中・重） 重症 / 非重症（PMR・SMR で閾値分離） A〜D ステージ分類（C1/C2 区分あり）
差異ポイント①

SMR の「重症」EROA 閾値は ESC が 0.30 cm²、ACC/AHA は 0.40 cm² と数値表記が異なる。ただし ACC/AHA も「2D PISA は SMR の ERO を過小評価する」と注釈しており、実臨床での解釈は近接する。

3. 慢性一次性（器質性）MRの介入適応

3-1. 症候性重症 PMR（共通 Class I）

推奨事項 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
症候性重症 PMR への僧帽弁手術 Class I, Level B（LVEF >30%） Class I, Level B Class I, Level B-NR（Stage D、LV 機能不問）
LVEF ≤30% の症候性重症 PMR Class IIa, Level C（弁膜症チームで症状改善期待時） 操作可能性を Heart Team で判断 Class I, Level B-NR（LV 機能不問の包括的推奨に含む）

3-2. 無症候性重症 PMR — LV 機能低下による絶対的介入

介入トリガー JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
LVEF ≤60% または LVESD ≥40 mm（LVESDi ≥24 mm/m²） Class I, Level B Class I, Level B（LVESD ≥40 mm or LVESDi ≥20 mm/m² or LVEF ≤60%） Class I, Level B-NR（Stage C2：LVEF ≤60% かつ/または LVESD ≥40 mm）
差異ポイント② — LVESDi 閾値

JCS は LVESDi ≥24 mm/m²、ESC は LVESDi ≥20 mm/m² と異なる。日本人の体格を反映してJCSはやや高い閾値を採用しているが、絶対値の LVESD ≥40 mm は3ガイドライン共通。

3-3. 無症候性重症 PMR — リスクマーカー陽性での予防的介入

介入トリガー JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
新規発症 AF または安静時 SPAP/PASP >50 mmHg Class IIa, Level B Class IIa, Level B（PH or AF secondary to MR） 個別判断（明示的閾値なし、Stage C1 でリスク評価）
LA 拡大（LAVI ≥60 mL/m² または LA径 ≥55 mm） LA容量係数 ≥60 mL/m² → Class IIa, Level C（条件付き） Class IIa, Level B（弁形成 likely な低リスク例） 早期手術戦略の根拠として記載
LV 機能正常な低リスク例での予防的弁形成（durable repair likely） 該当：耐久性ある弁形成が安全に施行可能と判断される場合 → Class IIa, Level C Class I, Level B（AF・PH・LA拡大・中等度以上TR の 3項目以上を満たし、Heart Valve Centre で durable repair likely） Class IIa, Level B-NR（成功 durable repair 確率 >95%、術死 <1%、Primary or Comprehensive Valve Center）
進行性に LVEF 低下／LVESD 増大（3回以上のシリアル画像） Class IIb, Level C （継続経過観察の文脈で言及） Class IIb, Level C-LD
差異ポイント③ — 「予防的」弁形成の推奨強度

ESC/EACTS 2025 は「低リスク無症候性重症 PMR で AF・PH・LA拡大・中等度以上TR の 3項目以上 + durable repair likely + Heart Valve Centre」を Class I, Level B として弁形成を推奨。これは3ガイドラインの中で最も積極的な早期手術推奨。 ACC/AHA は同様の状況を Class IIa, Level B-NR とし、成功率 >95% かつ術死 <1% という定量基準を課す。 JCS も Class IIa として「安全に耐久性のある形成が可能」と概念的に類似するが、定量基準はやや控えめ。

3-4. 弁形成術 vs 弁置換術の原則（PMR）

原則 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
形成可能症例での弁形成術選択 Class I, Level B Class I, Level B（result durable と期待される場合） Class I, Level B-NR（変性性 MR で durable repair が可能な場合）
後尖単独限局病変での弁形成の絶対的優位 標準術式（記載あり） 簡易病変として記載 Class 3: Harm, Level B-NR（後尖 <1/2 限局例で弁形成を試みずに置換することは禁忌）
複雑病変（前尖・両尖・Barlow）の弁形成 Heart Valve Center で経験豊富な術者へ集約を示唆 Heart Valve Centre 推奨、術死 1.2% と報告 Comprehensive Valve Center / 高ボリュームセンターを推奨
腱索温存 MVR Class 記載なしも明確に推奨（後尖腱索温存は左室破裂予防） 当然の推奨として記載 Chordal-sparing MVR を推奨
ACC/AHA の独自・強力な禁忌規定（差異ポイント④）

ACC/AHA 2020 は 「後尖 <1/2 の限局病変で、Primary/Comprehensive Valve Center で形成を試みずに弁置換することは Class 3: Harm, Level B-NR」 と明記。形成成功率 ≥95% が期待できる病変での MVR は明示的に禁忌。

3-5. PMR への TEER の適応

推奨事項 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
症候性重症 PMR で手術高リスクまたは禁忌 TEER（MitraClip®）：症候改善期待・形態適合・LVEF ≥30% で適応（表17） Class IIa, Level B（症候性重症 PMR で解剖学的適合かつ高外科的リスク） Class IIa, Level B-NR（NYHA III/IV の重症症候性、高 or 禁忌的手術リスク、形態適合、余命 ≥1年）
NYHA II・症状軽度での TEER 適応外（重症症候性のみ） 同左 同左

全ガイドラインで「手術第一選択 + 手術不能/高リスクの症候性重症例にTEER」という枠組みは共通。Class は IIa（ESC・ACC/AHA） vs JCSの表17適用基準で実質的に同等。

4. 慢性二次性（機能性）MR—心室性SMRの介入適応

4-1. 治療階層の大前提：GDMT・CRT 最適化が先

3ガイドライン共通

**心室性 SMR は「心室の疾患」**であり、MV 介入の前に GDMT（ACE-I/ARB/ARNI + β遮断薬 + MRA + SGLT2i）の最大耐用量 および適応があれば CRT を最適化することが Class I 推奨（JCS：表14、ESC：Section 9.2.4.1、ACC/AHA：Section 7.3.3）。GDMT 適正化により約 40% で SMR が1段階以上改善する（ESC 9.2.4.1）。

4-2. CABG 同時施行（虚血性 SMR）

状況 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020
CABG 適応 + 重症 MR + LVEF >30% Class I, Level C Class I, Level C（重症 MR + 他弁術または CABG 時の同時 MV 手術） Class IIa, Level B-NR（重症 SMR + CABG 施行時の MV 手術）
CABG 適応 + 重症 MR + LVEF ≤30% Class IIb, Level C 個別 Heart Team 判断 （同上の包括的記載）
CABG 適応 + 中等症 MR + 後下壁にバイアビリティあり Class IIb, Level B（CABG単独優先） Class IIb, Level B（中等症 SMR + CABG 時の MV 手術考慮） （RCT で長期 MR は減るが死亡改善なしと記載）
CABG 適応 + 中等症 MR + 後下壁にバイアビリティなし Class IIb, Level C（CABG + 弁輪形成） 同上 同上

4-3. CABG 適応なしの単独 MR 介入（重症心室性 SMR）

状況 JCS 2020 ESC/EACTS 2025 ACC/AHA 2020

5. 慢性二次性（機能性）MR—心房性SMRの介入適応

5-1. 心房性 SMR の概念と診断基準

心房性 SMR（atrial SMR） の定義（ESC/EACTS 2025 Figure 12）

以下の 全項目 を満たす：

  • 保持された LVEF（≥50%） かつ局所壁運動異常・弁尖テザリングなし
  • LV 内腔正常 or 軽度拡大（女性 LV拡張末期径 <56 mm / 男性 <63 mm; iLVEDV 女性 <71 mL/m² / 男性 <79 mL/m²）
  • 僧帽弁輪拡大（AP 径 >35 mm）
  • 左房拡大（LAVI >34 mL/m²）

加えて 臨床的に AF 既往または HFpEF の診断 を伴うことが多い。

JCS 2020 第2章5節も「左房・弁輪拡大に伴う弁尖・腱索の器質的異常を伴わない MR」として概念的に同等の定義を採用しており（LVEF ≥50%、長期持続性 AF や HFpEF に好発）、後尖の hamstringing・前尖の pseudoprolapse を典型所見として記述。 ACC/AHA 2020 はステージ表内に独立分類は設けないが、表18 Stage C/D の解説で「LA 拡大による弁輪拡大と接合不全」を独立病態として記載（HFpEF・拘束型・非閉塞性 HCM・AF 関連）。詳細は 心房性MR定義まとめ を参照。

10. まとめ・総括

共通事項

3ガイドライン共通の合意事項
  1. 症候性重症 PMR への MV 手術は Class I（LVEF 不問）
  2. 無症候性重症 PMR でも LVEF ≤60% or LVESD ≥40 mm を満たせば Class I で手術（数値はほぼ共通）
  3. 形成可能症例での弁形成術は弁置換術より優先（Class I）
  4. 腱索温存 MVR（特に後尖腱索）が標準
  5. **心室性 SMR は「心室の疾患」**であり、GDMT + CRT 最適化が MV 介入前の前提
  6. COAPT 基準を満たす持続性重症 SMR には TEER が有効（推奨強度は差あり：I-A〜IIa-B-R）
  7. CABG 同時の重症 SMR には MV 手術同時施行を考慮
  8. 心房性 SMR は独立した病態として認識され、リズム管理・弁輪縫縮・LAAO が中心
  9. 症候性重症 PMR で手術高リスク/不能例には TEER が有効（Class IIa）
  10. PMR/SMR で重症度の評価指標と閾値は異なる（特に EROA：PMR ≥0.40 vs SMR ≥0.30 cm² in ESC）

主要な相違点まとめ

# 相違点 詳細
① SMR の重症度閾値 ESC は SMR で EROA ≥0.30 cm²、RVol ≥45 mL と PMR より低閾値を採用。ACC/AHA は同じ ≥0.40 cm² 数値だが PISA 過小評価を注記。JCS は PMR と同基準
② 無症候性 PMR の LVESDi JCS ≥24 mm/m²、ESC ≥20 mm/m²、ACC/AHA は明示閾値なし（LVESD ≥40 mm のみ）。日本人体格を反映してJCSはやや高い閾値
③ 低リスク無症候性重症 PMR への予防的弁形成 ESC が最も積極的（Class I, Level B：AF・PH・LA拡大・TR の3項目以上 + Heart Valve Centre + durable likely）。ACC/AHA は Class IIa で成功率 >95%、術死 <1%、Primary/Comprehensive Valve Center を要件化
④ 後尖単独 PMR で形成試行せず置換 ACC/AHA のみが Class 3: Harm, Level B-NR として明示的禁忌。JCS・ESC は推奨外として言及にとどまる
⑤ 心室性 SMR への TEER 推奨強度 ESC 2025 が COAPT・RESHAPE-HF2 メタ解析を根拠に Class I, Level A に格上げ（2025年最大の改訂）。ACC/AHA は Class IIa, Level B-R（COAPT vs MITRA-FR 格差考慮）。JCS は LVEF ≥30% で個別判断
⑥ 心房性 SMR への外科手術強度 ESC Class IIa, Level B、JCS Class IIa, Level C、ACC/AHA Class IIb, Level B-NR。ESC が最も明示的に MV + Maze + LAAO のセット手術を推奨
⑦ CABG 同時 SMR で MVR vs 形成 ACC/AHA のみが CTSN RCT を根拠に「Chordal-sparing MVR ≥ downsized annuloplasty 形成」と明記（Class IIb, Level B-R）
⑧ TEER の LVEF 下限 日本 ≥30%、米国 ≥20%、欧州 ≥15%（日本が最厳格）
⑨ AF カテーテル・アブレーションの位置付け JCS が心房性 SMR への治療として Class IIa, Level C と最も明示的
⑩ TMVI for MAC（経カテーテル僧帽弁植え込み） ESC/EACTS 2025 のみが MS の項目で Class IIb, Level C として記載

臨床的含意

地域別アプローチの特徴
  • 🇪🇺 欧州（ESC/EACTS 2025） は (1) 低リスク無症候性 PMR への予防的弁形成を Class I に格上げ（3項目以上のリスクマーカー + Heart Valve Centre）、(2) 心室性 SMR への TEER を Class I, Level A に格上げ（COAPT/RESHAPE-HF2 メタ解析）、(3) 心房性 SMR への外科手術（MV + Maze + LAAO）を Class IIa, Level B と明示 という3点で最も積極的・先進的。Heart Valve Centre / Heart Team / 個別解剖評価を重視し、SMR で EROA 閾値を ≥0.30 cm² に下げているのも特徴。
  • 🇺🇸 米国（ACC/AHA 2020） は A〜D ステージ分類による明確な患者層別が特徴で、(1) 症候性重症 PMR への手術を Class I, Level B-NR で LV 機能不問、(2) 後尖単独 PMR で形成を試みずに置換することを Class 3: Harm と禁忌化、(3) 虚血性 SMR への CABG 同時 MV 手術で chordal-sparing MVR を formed/downsized annuloplasty 形成より優先（CTSN RCT 根拠） が独自の強い推奨。一方で TEER（特に SMR）への姿勢は ESC より慎重（IIa）。
  • 🇯🇵 日本（JCS 2020） は (1) LVESDi ≥24 mm/m² と日本人体格を考慮した閾値、(2) MitraClip® 適用基準（表17）で LVEF ≥30% と最も厳格、(3) AF カテーテル・アブレーションによる心房性 SMR への治療効果を Class IIa, Level C として明記、(4) 後尖腱索温存 MVR を左室破裂予防として強く推奨、(5) リウマチ性 MR や透析患者の弁輪石灰化など日本特有の病態への配慮 が特徴。重症度分類は伝統的な3段階（軽・中・重）を維持。

実臨床での意思決定フレームワーク

MR 介入の意思決定アルゴリズム（3ガイドライン統合）

Step 1：MR を一次性 vs 二次性に分類（弁尖の器質的異常の有無）

Step 2：二次性なら 心室性 vs 心房性 に分類（LVEF・LV サイズ・LA サイズで判定、ESC Figure 12 基準）

Step 3：重症度を多指標で総合評価（PMR/SMR で閾値が異なる点に注意、PISA は SMR で過小評価）

Step 4：症状の有無と LV/LA 機能を評価

  • 症候性重症 PMR：MV 手術 Class I（高リスクは TEER 検討）
  • 無症候性重症 PMR + LVEF ≤60% or LVESD ≥40 mm：MV 手術 Class I
  • 無症候性重症 PMR + LV 機能正常 + リスクマーカー（AF/PH/LA拡大/TR）：Heart Valve Centre で durable repair likely なら早期手術考慮（推奨強度に地域差あり）

Step 5：二次性 MR は GDMT + CRT 最適化が前提

  • 持続性重症心室性 SMR + COAPT 基準：TEER（ESC: Class I-A, ACC/AHA: Class IIa-B-R）
  • 重症心房性 SMR：MV 手術 + Maze + LAAO を Heart Team で（リズム管理・AF アブレーションを先行）

Step 6：弁形成 vs 置換は病変解剖と術者経験で（後尖単独 PMR は形成必須、複雑病変は Heart Valve Centre 集約）

本文書は各ガイドライン原本の推奨事項を忠実に要約したものです。推奨クラス（I, IIa, IIb, III）およびエビデンスレベル（A, B, C）は原文に基づき記載しています。実際の臨床判断は各症例の状況を踏まえ、弁膜症チーム（Heart Team / Heart Valve Team）にて総合的に行うことが推奨されます。EROA・RVol・LVESD・LVEF などの数値閾値は将来改訂で変更される可能性があるため、最新版のガイドライン本文を参照してください。
