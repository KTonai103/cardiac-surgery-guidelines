1. 臨床的背景と本ドキュメントの位置づけ

心臓手術の術前には経口抗凝固薬（OAC）の休薬が必要となるが、休薬期間中の血栓塞栓症リスクと、ヘパリンブリッジングによる出血リスクのバランスが臨床上の重要課題である。

BRIDGE試験（2015年）

本領域の最大のエビデンスはBRIDGE試験（Douketis et al., NEJM 2015）である。非弁膜症性AF患者1,884人を対象に、ワルファリン休薬時のLMWHブリッジング群 vs プラセボ群を比較。

  • 血栓塞栓症：差なし（ブリッジ群 0.3% vs 非ブリッジ群 0.4%）
  • 大出血：ブリッジ群で有意に増加（3.2% vs 1.3%, P = 0.005）
  • 対象のCHADS₂スコアは平均2.3（範囲1-6）

ただし、機械弁・最近の脳卒中/TIA・弁膜症性AF（リウマチ性MS）は除外されている。

心臓手術への外挿の限界

BRIDGE試験は主に非心臓手術・侵襲的処置を対象としている。開心術への直接的な外挿には限界があり、EACTS 2024が心臓手術に特化した数少ないガイドラインである。

4. ヘパリンブリッジングの適応

4-1. 各ガイドラインのブリッジング適応基準

地域間で最も大きな乖離がある領域

ヘパリンブリッジングの適応基準はガイドライン間で最も見解が分かれる領域である。特にAF患者のCHA₂DS₂-VASc スコアに基づく層別化において、米国と欧州・日本で立場が大きく異なる。

DOAC服用中 ブリッジ不要 ブリッジ不要 (I, B) — 「考慮」の表現

4-2. 各ガイドラインの推奨文（原文要約）

🇺🇸 ACC/AHA/HRS 2023

Class I, Level B-R：AF患者（機械弁・最近の脳卒中/TIAを除く）でOAC服用中、手術のためにワルファリンまたはDOACを休薬する場合、ブリッジング抗凝固療法なしでの一時的休薬を推奨する。

Class III: Harm, Level B-R：AF患者でワルファリン休薬中のLMWHによるブリッジング抗凝固療法は投与すべきではない（機械弁・最近の脳卒中/TIAを除く）。

Class III: Harm = 最も強い「やるな」推奨

ACC/AHAの推奨クラス体系においてClass III (Harm) は「有害であり、行うべきではない」を意味する。CHA₂DS₂-VASc 6点までの患者でもブリッジの利点はなく、出血が有意に増加した。

🇪🇺 EACTS 2024

Class I, Level C：高い血栓リスクを有するVKA患者では、ヘパリンブリッジングを推奨する。対象：機械弁、AF+リウマチ性弁膜症、12週以内の急性血栓イベント、先天性/後天性血栓性素因、左室心尖部血栓。

Class I, Level B：DOAC休薬時には、ルーチンのヘパリンブリッジングは不要。

🇪🇺 ESC/EACTS 2025 VHD

Class I, Level C：OAC中断が必要な場合、以下の患者にはブリッジングを推奨する：(1) 機械弁、(2) AF+有意なMS、(3) AF + CHA₂DS₂-VASc ≥ 3（女）or ≥ 2（男）、(4) 4週以内の急性血栓イベント、(5) 高い急性血栓塞栓リスク。

🇯🇵 JCS 2020

「特に血栓塞栓症のリスクが高い症例（機械弁、脳梗塞の既往、CHA₂DS₂-VASc score 2点以上）では置換を前提に術前管理することが望ましい」

DOACについては「必要に応じてヘパリン置換を行う」「ヘパリン置換を考慮する」と記載。

5. AF単独患者のブリッジング：地域間の相違

臨床上最も重要な問い

「AF患者であるというだけで、術前入院後にヘパリン化は必要か？」

5-1. 回答：ガイドラインにより異なる

準拠ガイドライン AF単独でのブリッジング 条件
🇺🇸 ACC/AHA/HRS 2023 不要（有害） CHA₂DS₂-VAScに関わらず（機械弁・最近の脳卒中除く）
🇪🇺 EACTS 2024 不要 非弁膜症性AFは高リスク群に含まれない
🇪🇺 ESC/EACTS 2025 VHD CHA₂DS₂-VASc依存 ≥ 2（男）/ ≥ 3（女）で推奨
🇯🇵 JCS 2020 CHA₂DS₂-VASc依存 ≥ 2 で望ましい

5-2. 実臨床での含意

CHA₂DS₂-VASc ≥ 2 は低い閾値

CHA₂DS₂-VASc ≥ 2（男性）は非常に低い閾値である。例えば、65歳以上の高血圧合併AF患者は自動的にスコア2以上となる。心臓手術を受ける患者の多くは高齢であり、ESC/JCSの基準では大半のAF患者がブリッジ対象となりうる。

一方、ACC/AHAはCHA₂DS₂-VASc 6点の患者を含むBRIDGE試験データに基づき、スコアに関わらず不要としている。

5-3. DOACの場合

準拠ガイドライン DOAC服用中のAF患者のブリッジ
🇺🇸 ACC/AHA/HRS 2023 不要
🇪🇺 EACTS 2024 不要（Class I, Level B）
🇪🇺 ESC/EACTS 2025 VHD 明確な記載なし
🇯🇵 JCS 2020 「必要に応じて」「考慮する」の表現（DOACでもヘパリン置換に言及）
DOACとブリッジングの根拠

DOACは半減期が短く薬物動態が予測しやすいため、休薬と再開のタイミング管理が容易である。これがブリッジ不要の主な理由であり、ワルファリンの半減期の長さ・個体差とは対照的である。

6. ブリッジングの実施方法

6-1. ヘパリンの選択と投与

項目 推奨内容
薬剤選択 UFH（未分画ヘパリン）またはLMWH（低分子ヘパリン）（EACTS 2024: Class I, Level B）
UFH投与量調整 APTT が正常対照値の1.5〜2.5倍に延長するように（JCS 2020）
UFH中止タイミング 手術の4〜6時間前（JCS 2020）/ 2〜4時間前（EACTS 2024: Class I, Level C）
LMWH最終投与 手術の12〜24時間前（EACTS 2024: Class I, Level B）
フォンダパリヌクス 半減期が長い（17-21時間）ため、ブリッジングには推奨されない（EACTS 2024）
UFH vs LMWH

LMWH は持続静注や頻回のモニタリングが不要で管理が容易。ただし、プロタミンで完全に中和できない点に注意が必要。ESC 2025 VHDでは、MHV術後のブリッジングにおいてUFHの方がLMWHよりやや出血率が低い可能性が2つのメタ解析で示唆されている。

6-2. 術後の抗凝固再開

項目 🇺🇸 ACC/AHA/HRS 2023 🇪🇺 ESC/EACTS 2025 VHD
低出血リスク手術後 翌日にDOAC再開 —
高出血リスク手術後 術後2-3日目の夕方にDOAC再開 —
MHV術後 — 24時間以内にUFH/LMWHブリッジ + VKA開始（Class I, Level B）
VKA到達確認 — INRが治療域内で2日連続確認後にヘパリン中止

7. 機械弁患者の周術期管理

全ガイドラインで一致

機械弁患者のワルファリン休薬時はヘパリンブリッジングが推奨される——これは全ガイドラインで共通の立場である。

血栓促進リスク因子：先天性/後天性凝固亢進状態、LV機能低下（LVEF < 35%）、AF+有意なMS、12ヶ月以内の重大血栓イベント

機械弁にDOACは禁忌

全ガイドラインが一致：機械弁患者にDOACは使用してはならない（ESC 2025: Class III, Level A）。RE-ALIGN試験で早期中止。

8. 緊急手術時の抗凝固薬中和

8-1. DOAC中和薬

薬剤 中和薬 推奨
ダビガトラン イダルシズマブ EACTS 2024: Class IIa, Level B
FXa阻害薬（アピキサバン、リバーロキサバン、エドキサバン） アンデキサネット アルファ 使用可（JCS 2024に記載）
アンデキサネット アルファとCPBの併用禁忌

EACTS 2024は、CPB使用の緊急心臓手術において、CPB離脱前のアンデキサネット アルファ投与は推奨しない（Class III: Harm, Level C）。一過性のヘパリン抵抗性を引き起こすリスクがある。

8-2. ワルファリン中和（ESC/EACTS 2025 VHD）

  • 生命を脅かす出血・緊急手術時：VKA中止 + 4因子プロトロンビン複合体製剤（PCC）（FFPより推奨）
  • 機械弁患者では血栓リスクを考慮し、PCCの開始量を減量（25 IU/kg → 12.5 IU/kg）も考慮
  • 大出血制御後、可及的速やかにVKA再開

9-2. 「弁膜症性」vs「非弁膜症性」AFの定義

JCS 2020の重要な再定義

JCS 2020は「弁膜症性AF」の定義を変更した：

  • 弁膜症性：機械弁と僧帽弁狭窄症（MS）のみ
  • 非弁膜症性：生体弁術後、僧帽弁形成術後、非リウマチ性MR、大動脈弁疾患、三尖弁疾患

→ 生体弁 + AF の組み合わせでも「非弁膜症性」として扱われ、DOACが使用可能。

10. まとめ・総括

全ガイドライン共通事項

  • 機械弁・リウマチ性MSでのワルファリン休薬時は、全ガイドラインでヘパリンブリッジングが推奨される
  • DOAC服用患者は、薬物動態が予測しやすく休薬・再開管理が容易なため、ブリッジングの必要性は低い
  • BRIDGE試験（2015年）の結果は全ガイドラインで引用されている
  • 機械弁にDOACは禁忌（全ガイドライン一致）

主要な相違点まとめ

臨床上の最大の分岐点

AF患者のブリッジング適応が地域間で最も大きく異なる：

  • 🇺🇸 米国（ACC/AHA）：AF単独ではCHA₂DS₂-VAScに関わらずブリッジ不要。ブリッジは有害（Class III: Harm）
  • 🇪🇺 欧州（ESC/EACTS）：CHA₂DS₂-VASc ≥ 2（男性）/ ≥ 3（女性）でブリッジ推奨。ただし心臓手術特化のEACTS 2024ではリスク因子列挙方式
  • 🇯🇵 日本（JCS）：CHA₂DS₂-VASc ≥ 2でブリッジ「望ましい」。DOACでもヘパリン置換に言及

臨床的含意

  1. どのガイドラインに準拠するかを施設として明確にすることが重要。同じAF患者でも、ガイドラインによりブリッジの推奨が正反対になりうる
  2. 心臓手術を受けるAF患者の大半はCHA₂DS₂-VASc ≥ 2を満たすため、ESC/JCS基準では実質的に多くの患者がブリッジ対象となる
  3. DOAC服用中の患者では、ガイドライン間の差は比較的小さい（概ねブリッジ不要）
  4. BRIDGE試験の除外基準（機械弁、最近の脳卒中、弁膜症性AF）に該当する患者群は、依然としてエビデンスが不足しており、個別判断が求められる

本文書は各ガイドライン原本の推奨事項を忠実に要約したものです。推奨クラス（I, IIa, IIb, III）およびエビデンスレベルは原文に基づいています。実際の臨床判断は各症例の状況を踏まえ、弁膜症チーム（Heart Teamまたは専門医間の協議）にて総合的に行うことが推奨されます。
