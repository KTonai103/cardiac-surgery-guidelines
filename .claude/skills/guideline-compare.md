# Guideline Compare Skill

一つの臨床テーマに対する各地域（日本・米国・欧州等）のガイドラインを、PDFリファレンスから体系的にリサーチし、**Part I: 各ガイドラインの個別概要** と **Part II: ガイドライン横断的比較** で構成されるMDファイルとHTMLファイルを作成するスキル。

## 入力

ユーザーから以下を確認する:
1. **臨床テーマ**（例: 上行大動脈手術適応、僧帽弁手術適応）
2. **参照PDFの場所**（`reference/` ディレクトリ等。地域別サブフォルダ構成を想定）
3. **出力ファイルパス**（MD/HTML）

もし指定がなければ、作業ディレクトリの `reference/` フォルダを探索し、地域別PDFを自動検出する。

## ワークフロー

### Phase 1: 構造化 & リサーチ（並列Agent）

1. `reference/` ディレクトリを探索し、地域別（Japan, US, Europe等）のPDFを特定する
2. 各地域について**並列でAgentを起動**し、以下を抽出する:
   - ガイドラインの正式名称、発行団体、発行年、ジャーナル
   - 推奨クラス/エビデンスレベルの体系
   - 臨床テーマに関連する推奨内容（径閾値、Class/LOE、条件等）を**原文ベース**で抽出
   - 各ガイドライン独自の特徴・視点
   - 径の測定方法や定義の差異

各Agentへのプロンプトには以下を含める:
- 対象PDFのファイルパス
- 抽出すべき情報の具体的なリスト
- 「事実ベースで、原文の推奨文やClass/LOEを正確に引用」の指示

### Phase 2: 各論執筆（Part I）

リサーチ結果をもとに、**JCSから始めて**各ガイドラインの個別概要セクションを執筆する:
- 各ガイドラインごとに: 概要ボックス（正式名称・発行団体・発行年・スコープ・測定方法）、推奨表、特徴リスト
- 順序: JCS（日本）→ ACC/AHA（米国）→ ESC/EACTS（欧州）→ その他（AATS等）
- 推奨表は原文の推奨クラス・エビデンスレベルを正確に反映

### Phase 3: 横断比較執筆（Part II）

Part Iの情報を統合し、疾患・条件別の横断比較表を作成する:
- 各カテゴリごとに全ガイドラインを列に並べた比較表
- リスク因子の定義比較
- 閾値の相違点のまとめ
- 測定方法の比較
- 統合サマリー表
- 臨床上の注意点

### Phase 4: ファクトチェック（並列Agent）

完成した文書について、**地域別に並列でファクトチェックAgentを起動**する:
- 各Agentは担当地域のPDF原文と照合し、以下を確認:
  - 径閾値の数値（mm/cm単位）
  - 推奨クラス（I/IIa/IIb/III）
  - エビデンスレベル（A/B/C, B-R/B-NR/C-LD/C-EO等）
  - リスク因子の定義
  - 表番号・Figure番号の参照
- 誤りがあれば具体的に報告（箇所、現在の記載、正しい値、PDF出典）
- 報告された誤りを修正

### Phase 5: 出力

以下の2ファイルを生成する:

**MDファイル**: 標準的なMarkdown形式
- Part I と Part II を `---` で区切る
- 表はMarkdown table記法

**HTMLファイル**: 閲覧用にスタイル付きHTML
- 地域別カラータグ（JPN=赤系、USA=青系、EUR=緑系等）
- sticky headerの比較表
- レスポンシブ対応
- 目次ナビゲーション
- 印刷対応CSS

## 品質基準

- 全ての推奨値はPDF原文から直接引用し、推測や記憶に基づく記載を含めない
- Class/LOEは各ガイドラインの体系に沿って正確に表記する
- ガイドライン間で異なる測定方法や定義の差異を明示する
- 「記載なし」「--」を適切に使い分け、不在の情報を明確にする
